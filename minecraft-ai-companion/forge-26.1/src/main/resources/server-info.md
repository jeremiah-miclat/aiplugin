# Server Reference

This is the ONLY source of truth the AI companion has for questions about your server. If a
player's question isn't answered by something in this file (or by a file in kb/), the bot will
say it doesn't have that information — it never guesses or claims to search the web.

Replace everything below with your own server's actual details. Short, factual bullet points work
best — this gets pasted directly into the AI's prompt on every question, so keep it tight rather
than turning it into marketing copy.
