# Exporting the SVGs to PNG for Modrinth

Modrinth's icon and gallery-image uploaders want raster files (PNG/JPG/GIF/WEBP), not SVG, so
these three vector files need one conversion step first. They were drawn as SVG (not generated by
an image model) so you can freely tweak colors/text/wording before exporting — open any of them in
a browser or text editor to see what's inside.

## Files

| File | Use for | Export size |
|---|---|---|
| `icon.svg` | Modrinth project icon | 512×512 (square) |
| `gallery-overview.svg` | Gallery image #1 — feature overview | 1920×1080 |
| `gallery-platforms.svg` | Gallery image #2 — supported platforms | 1920×1080 |

Modrinth's actual minimums are lower (icon ≥ 64×64, gallery images have no strict minimum), but
512×512 / 1920×1080 are comfortably sharp on any display Modrinth uses these images at, and match
the `viewBox` each SVG was already drawn at 1:1, so no scaling artifacts.

## Easiest option — no software install

1. Open [cloudconvert.com/svg-to-png](https://cloudconvert.com/svg-to-png) (or any other
   browser-based SVG→PNG converter you trust).
2. Upload the `.svg` file.
3. Set width/height to the sizes in the table above (the converter should offer a size field —
   if it only offers a scale %, the source `viewBox` is already 512×512 or 1920×1080, so 100%
   scale gives you the exact target size).
4. Download the `.png` and upload that to Modrinth.

## If you have Inkscape (free, open source)

```
inkscape icon.svg -w 512 -h 512 -o icon.png
inkscape gallery-overview.svg -w 1920 -h 1080 -o gallery-overview.png
inkscape gallery-platforms.svg -w 1920 -h 1080 -o gallery-platforms.png
```

## If you have a browser only, no installs, no uploads

Open the `.svg` file directly in Chrome/Edge/Firefox, zoom so it fills the window, and use the
browser's screenshot/print-to-image tool — lower fidelity than the two options above (font
rendering can shift slightly between browsers), but works with zero tools.

## Editing before exporting

Each SVG is plain text — open it in any text/code editor to change the project name, colors
(`#7c5cff` purple / `#33d6c0` teal are the two accent colors used throughout, `#160b2b` / `#33165c`
are the background gradient), or wording, then re-export. Keep the two accent colors consistent
across `icon.svg` and both gallery images if you tweak one, so the project has one visual identity
across Modrinth's icon + gallery thumbnails.
